# MeBox-APP

MeBox 的原生 Android 客户端（Kotlin + Jetpack Compose）。

## 当前能力

- 服务器地址解析、连接测试与 HTTP 风险确认
- 账号登录、会话安全保存、冷启动自动恢复与退出
- 影视：首页按媒体库分区展示最近更新、继续观看与焦点推荐轮播；媒体库两列封面索引、
  浏览页支持海报/宽幅两种网格与筛选排序随机播放、搜索分页；沉浸式详情页提供
  评分与元数据、简介展开、季/集切换；多季条目默认展开第一季，「继续播放」
  指向本剧最新观看的那一集；收藏列表与观看历史（进度、删除单条、清空）
- “我的”页提供“我的收藏”和“观看历史”入口；详情页收藏状态与收藏列表保持同步
- 首页焦点推荐轮播：读取服务端 `carousel_enabled` 媒体库的预览卡片，5 秒自动轮播，
  支持左右滑动和圆点指示；没有配置轮播库时退回“最近添加”
- 自绘播放器，支持切换播放内核：默认 Media3 ExoPlayer（硬件解码优先），可在
  「我的 → 播放设置」或播放页「更多 → 播放内核」切换到 LibVLC（内置 FFmpeg 软解），
  用于系统解码器不支持的容器/编码；切换后从当前位置继续播放。进入播放页自动横屏、
  退出恢复原方向；顶部标题栏 + 底部图标控制条；双击/横滑快进、
  左侧亮度与右侧音量手势带侧边指示器，横向拖动显示目标时间；倍速、清晰度、音轨、
  字幕、画面缩放收进「播放设置」面板；支持画中画、锁屏、下一集，
  播放结束后倒计时自动接下一集（可取消）
- 纯直连播放：服务端只返回 `/api/stream/:id` 直链，App 在设备本地解码，不请求
  HLS、服务端转码或字幕烧录；解码能力只用于起播提示，失败时提示切换播放内核
- 字幕：内嵌文本字幕由 ExoPlayer 直接从视频容器解析并渲染；外挂字幕通过服务端
  转成 WebVTT 后加载。PGS/DVD 等图片字幕 App 无法渲染，不会出现在字幕列表
- ASS/SSA 样式：服务端的 WebVTT 接口会剥掉样式，App 额外请求
  `/api/subtitles/:id/ass` 拿到原始 ASS。系统解码内核用 Media3 的 SsaParser
  还原行内颜色、粗体、斜体、下划线和位置；LibVLC 内核由 libass 进一步还原
  字体、描边、定位与淡入淡出。
- 断点续播：播放中每 5 秒写本地缓存，每 15 秒同步服务端；暂停/退出/播完立即上报
- VR / 全景播放：播放页「更多 → VR / 全景」支持 360°/180° 投影、单目/左右（SBS）/
  上下（TB）立体格式、手机全屏与头显双眼分屏；头部追踪优先使用游戏旋转矢量传感器，
  没有陀螺仪时可以拖动画面，并提供纸盒镜头畸变校正与「重新居中」。ExoPlayer 与
  LibVLC 都通过 SurfaceTexture 输出到同一个 OpenGL 渲染器

已知限制：

- 系统解码内核的播放格式取决于设备解码器：没有 HEVC/AV1 解码器的设备无法播放对应编码，
  也不支持 RMVB/WMV 等容器；这类片源可切换到 LibVLC 内核。LibVLC 以软件解码为主，
  功耗和发热更高，且发布包只包含 ARM 架构（调试包仍含 x86_64，供模拟器使用）。
- 图片字幕（PGS/DVD）需要位图字幕渲染，Media3 不支持，App 内不会显示；LibVLC 内核
  可以显示其中一部分。
- 外挂 ASS 字幕的服务端 WebVTT 转换会丢失排版；App 改为加载原始 ASS，系统内核
  能还原行内颜色/粗斜体/位置，LibVLC 由 libass 还原字体、描边与特效。字体仍依赖
  设备上可用的字体集合，ASS 里指定的非常用字体找不到时会被替换。
- 影视后台播放、播放会话隔离尚未实现；离开播放页会暂停。
- VR 模式依赖设备的旋转矢量传感器，没有陀螺仪时只能用手势拖动视角；头显分屏的
  镜头畸变校正是固定经验系数，不对应具体镜片参数。VR 下会暂时隐藏弹幕。
- LibVLC 内核的字幕由 VLC 自己渲染到视频输出上，VR 模式下会随球面弯曲；
  系统内核使用 App 的字幕层，左右眼各排一份。手机全屏模式只显示左眼画面。

阅读与听书限制：

- 听书新增「与其他应用同时播放」、播放期 WakeLock、电池优化授权入口与
  本地进度检查点；锁屏、耳机按键、来电和厂商省电策略仍未在真机验证。HLS 音轨
  不做离线缓存。定时关闭是单次会话行为，不会在下次打开时自动重新计时。
- 书源登录/验证码/段评只验证了自建测试源与接口链路，尚未用真实第三方登录
  样本验证 Cookie 与 XHR 代理。
- 离线缓存没有 WorkManager 后台任务、下载取消、过期版本与 LRU 容量管理；
  文本内嵌图片和部分上游资源可能无法离线。
- 冷启动时仍需先连接服务器恢复会话，完全离线启动尚未支持。
- 漫画路径尚未在真实漫画样本上验证；文本朗读（TTS）尚未实现。

- 阅读：书架（分组筛选、排序、目录更新、移出书架）、多源搜索与加入书架、
  目录跳转、原生纵向正文、主题/字号/行距/段距/夜间模式、阅读设置跨设备同步、
  阅读进度保存与本地恢复；图片型章节按图片顺序阅读
- 换源：按书名重新搜索并列出其他书源，切换后保留进度、清空旧源缓存并重建目录
- 段评：正文中的评论锚点按行显示气泡，点击在受控 WebView 里打开服务端签名评论页
- 听书：Media3 前台媒体服务，支持后台播放、通知栏/锁屏控制、自动下一章、
  与其他应用同时出声、播放期 WakeLock、电池优化入口、本地进度兜底，
  倍速、定时关闭、片头片尾跳过与按秒同步进度；播放页仿 Legado：模糊封面背景、
  大圆形封面、章节信息、白色圆形播放键、快退/快进、倍速与定时面板
- 书源登录与宿主页面：登录表单、待办轮询、受控 WebView、DOM 回传和页面内
  XHR 代理；WebView 不携带 MeBox 令牌，仅允许当前服务器同源地址
- 离线缓存：按账号/书籍保存目录、文本章节与图片/音频资源；支持缓存本章、
  后续 20 章、清除缓存，网络失败时自动回退离线内容

## 电视与遥控器

同一份 APK 同时支持手机与 Android TV（Leanback），启动时自动判断设备类型：

- 电视桌面通过 `LEANBACK_LAUNCHER` 显示；手机仍使用普通桌面入口。
- 电视界面为 10-foot 布局：左侧导航栏，方向键移动焦点，OK/Enter 确认，
  返回键回到上一级；卡片获得焦点会放大并显示强调色描边。
- 播放页遥控器映射：方向键上键显示控制栏并进入按钮焦点模式（方向键选择、OK
  确认），未进入焦点模式时 OK 播放/暂停、左右键快退/快进 10 秒、下键隐藏控制栏；
  菜单键打开右侧播放设置，返回键先退出焦点/收起控制栏、再退出播放页；媒体键
  （播放/暂停、快进、快退、下一集）同样可用。锁定、弹幕等入口都在焦点可达的
  面板/操作行里。
- 阅读页：上下键滚动，左右键切换章节，OK 隐藏/显示栏，菜单键打开目录。
- 电视上的文字输入统一走「手机扫码」：电视显示二维码，手机扫码后在同一
  局域网网页填写服务器地址、账号密码或搜索关键词，提交后立即推送到电视。
  页面地址带随机 token，关闭电视界面后服务立即停止，密码不会落盘。
- 播放页的弹幕面板支持手动搜索匹配：手机直接输入关键词；电视上点「手机扫码
  输入弹幕关键词」用手机填写，搜索结果与候选弹幕库回到面板里选择，并可一键
  恢复自动匹配。

## 构建与测试

```powershell
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleDebug
```

`assembleDebug` / `assembleRelease` 会按 ABI 拆分，同时生成 universal 包：

| 产物 | 适用设备 |
| --- | --- |
| `app-arm64-v8a-*.apk` | 主流手机、大多数电视盒子 |
| `app-armeabi-v7a-*.apk` | 老款设备 |
| `app-x86_64-*.apk` | Android TV 模拟器、Intel 设备 |
| `app-x86-*.apk` | 少数 32 位 x86 设备 |
| `app-universal-*.apk` | 不确定架构时使用，体积最大 |

调试 APK 位于 `app/build/outputs/apk/debug/`。
