# APP 阅读与听书预加载

## 行为

- 当前章优先显示或起播，不等待后续章节。
- 当前章加载成功后，在后台准备「当前章 + 后续 5 个可读章」。卷标题不计入，书尾不足 5 章时只加载剩余章节。
- 每次切章滚动窗口，复用已完整缓存或刚解析过的章节，仅补齐缺失部分。自动磁盘缓存保留同书「前 5 个可读章 + 当前章 + 后 5 个可读章」，卷标题不占数；过去未访问的章节不反向补下载。
- 文本保存正文，漫画下载图片，普通音频下载音轨至本机 reader-cache。HLS 和需要转码的音轨只预取地址，不声明为完整离线资源。
- 切章优先读取完整本机资源，其次使用预取的在线结果，未命中才请求服务端。在线地址在内存中最多保留 5 分钟，避免长期复用签名票。
- 后台听书的预加载运行在应用级作用域，离开阅读页面后继续；普通阅读离开页面后取消。
- 最多 2 个章节解析请求并发；媒体按章节顺序下载。单章失败不阻断其它章，当前章或近章不等待所有远章解析完成才开始下载。
- 使用现有书源媒体直连/代理开关。直连媒体下载沿用请求头登记与拦截器，不将书源请求头写入磁盘缓存。
- 换书、换源、停止听书、清缓存、退出账号时使旧任务失效；显式重试绕过预加载结果重新请求。
- 离线阅读模式不启动预加载。自动预加载使用临时分类，全局总预算 512 MiB（普通章节 384 MiB + 本地解码音源 128 MiB），超限先淘汰旧书旧章，不淘汰手动下载；剩余磁盘低于 128 MiB 时普通自动缓存停止落盘，当前章仍可在线阅读/播放。
- 手动「缓存本章 / 后续 20 章」持久标记为下载；已完整的自动缓存先原地提升，不依赖网络成功。不受滑动窗口和自动配额淘汰。历史未标记章节按下载保护，避免升级误删。
- 手机和电视的「我的 → 缓存与下载」按书籍统计自动缓存、下载及总占用；可分别清除自动缓存、删除下载、清空全部，均二次确认。清理正在听的书会先停止播放，清理使迟到写入失效。书籍进度和服务端原文件不受影响。
- 目录/身份文件计入分类占用；无下载时可随自动内容清理，手动下载所需目录随下载受保护。统计“项”包含完整及部分章节条目；同章若同时存在普通预加载和本地解码文件，会分开计项、真实累计字节。
- 本地软解音源按账号/书籍/章节/分轨归属；同章同轨的签名地址更新仅保留新版本。启动清理异常遗留半文件，退出账号清理该账号的两类自动目录。

## 实现

- `ReaderChapterPreloader.kt`：窗口、有限并发解析、资源下载、短期内存复用、缓存代次保护。
- `ReaderRepository.kt`：为阅读页和后台声音引擎提供同一份预加载器。
- `ReaderViewModel.kt`：文本/漫画预加载、切章复用与页面生命周期处理。
- `ReaderAudioEngine.kt`：起播后预加载、后台自动换章复用、重试与停止处理。
- `ReaderChapterPreloaderTest.kt`：窗口、卷标题、书尾、滚动补齐、音频/漫画实际下载、HLS、请求头、取消、换源、会话撤销及慢章节测试。
- `ReaderCachePolicy.kt` / `ReaderCacheStore.kt`：分类、窗口、预算、LRU、元数据迁移及选择性删除；后台声音和前台阅读分别保护当前章。
- `feature/cache/ReaderStorageDialog.kt`：手机/电视共用缓存管理，状态入口可独立做 Compose 界面测试。

预加载本身复用现有章节/媒体接口；下面的原生音频协商需要更新服务端后生效。

## APP 原始音频与本地解码

- APP 的单章、直连失败代理重试、批量章节请求均携带 `audio=native`，与 `media=direct/proxy` 独立。
- 服务端对本地有声书与 STRM 返回原始音轨的签名流地址，不因 WMA/ASF/APE 等浏览器兼容性触发 ffmpeg。网页未携带该参数时仍保留原有服务端转码。
- APP 先用 ExoPlayer 直接解码；HLS 显式设置 m3u8 类型（签名代理 URL 看不出后缀），不做 HLS→MP3 转码。
- 只有容器/解码器不支持时，切换 App 已内置的 LibVLC/FFmpeg 本地软解；这是直接解码播放，不额外编码生成 MP3，不占服务端转码 CPU。
- 普通远端不支持音轨会先经共享 OkHttp 下载到私有音源文件，保留防盗链头，64 MiB 单文件上限、128 MiB 本地回退缓存。已有本机预加载音轨直接使用。
- HLS 仍按流读取，不支持完整离线。极少数 Exo 不支持且带直连书源请求头的 HLS，VLC 回退会明确报错，需切到书源代理模式重试，不能无声丢弃 Cookie 等鉴权头。
- 本地软解也保留 Media3 会话、通知栏/耳机控制、倍速、定位、音频焦点及后台锁。解码失败不会触发服务器转码回退。
- 需要一起更新 APP 与 `C:/MyProject/MeBox` 服务端并重启服务；无数据库迁移、无需重新构建 Web。旧服务端不认识 `audio=native`，仍可能按旧规则下发转码地址。

## 验证

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

真机验收：打开一本在线文本/漫画/普通音频书，待后台任务完成后连续切换后 5 章，确认复用缓存；听书退回书架或息屏后等待自动换章；切换书源、清缓存及账号退出后确认旧资源不会重新写入。HLS 应继续按流播放，不应显示为完整离线缓存。
