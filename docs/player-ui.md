# 播放器界面与交互

播放页按 `CapyPlayer` 真实播放器截图复刻，不是早期营销图里的玻璃胶囊版本。
实现位于：

| 文件 | 职责 |
|---|---|
| `core/player/PlayerUiSettings.kt` | 手势/界面/方向/字幕外观偏好 |
| `feature/media/player/PlayerChrome.kt` | 横竖屏顶栏、底栏、进度条、传输键、侧边按钮、自绘图标 |
| `feature/media/player/PlayerQuickMenus.kt` | 内核/速度/音轨/字幕/弹幕贴边浮层、OSD |
| `feature/media/player/PlayerEpisodeStrip.kt` | 横向分集卡片 |
| `feature/media/player/PlayerSettingsHub.kt` | 播放器设置中心、媒体信息、定时关闭、字幕设置侧栏 |
| `feature/media/player/PlayerControls.kt` | 倍速/画质/音轨/字幕轨道/弹幕/VR 面板与状态层 |
| `feature/media/player/PlayerScreen.kt` | 内核接入、手势状态机、自动隐藏、锁屏、方向、PiP |

## 横屏布局

```
状态栏
X  媒体标题                                      [PiP][内核][弹][全屏][设置]
    E 服务器名
(锁)                                                                    (旋转)

   系列名
   S1E1 单集标题
   内核 容器
   00:19 ─────────────────────────────────────────────── 00:00
   ↺   ▶   ↻                                 [速度][分集][音轨][字幕]
```

- 左上：关闭 X、媒体标题；第二行是绿色服务器徽标 + 服务器显示名。
- 右上：一排线性图标，没有胶囊背景。内核和弹幕是圆形描边图标。
- 左右中部：锁定（开锁图标）和旋转。
- 左下：系列名（灰）、单集标题（白色粗体）、`EXO STRM` 技术信息、
  时间/进度条、快退/播放/快进。
- 右下：速度、分集、音轨、字幕四个入口。
- 状态栏保持可见；导航栏隐藏。顶栏用 `statusBarsPadding()` 避开状态栏。

## 竖屏布局

```
状态栏
X  媒体标题                         [PiP][内核][弹幕][投屏][设置]
(锁)

00:19 ───────────────────────────── 00:00
        1x    [分集]   [音轨]   [字幕]
```

竖屏不显示服务器行和旋转按钮；底栏使用同样的时间和四个操作入口。

## 分集卡片

点击「分集」后在控制栏上方浮出横向卡片：

- 16:9 剧照、圆角、选中集白色描边；
- 卡片下方是「第 N 集」和单集标题；
- 横向滚动，点空白处或返回键收起；
- 选择另一集后从该集重新起播，播放页返回目标保持不变。

数据来自 `MediaViewModel.state.episodes`，通过 `PlaybackRequest.episodes`
传入播放页；图片走服务端图片代理。

## 贴边浮层

右下/右上的入口不再打开底部 Sheet，而是贴着图标弹出深灰卡片（250dp 左右、
16dp 圆角、行高 44dp）：

| 浮层 | 内容 |
|---|---|
| 内核 | 播放内核（当前：EXO/VLC）、OSD 信息 |
| 速度 | 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× / 3× |
| 音轨 | 自动 + 当前音轨列表，选中项蓝色 + 勾 |
| 字幕 | 关闭、搜索在线字幕、字幕设置 |
| 弹幕 | 启用弹幕开关、匹配状态、搜索弹幕、显示设置 |

字幕浮层只保留真实截图里的三行；字幕轨道选择放在「字幕设置」侧栏里。
弹幕浮层的状态会根据自动匹配结果显示「作品 · 第 N 话 · 条数」或
「未找到匹配，请尝试手动搜索 / 点击搜索」。

## 字幕设置侧栏

从字幕浮层的「字幕设置」进入，横屏是右侧约 420dp 的全高侧栏：

- 顶部标题「字幕设置」+ 关闭 X；
- 说明：ASS/SSA 按脚本原样显示，样式调整仅对 SRT/VTT 生效；
- 紫色粗轨道滑块：垂直位置（0–100，默认 95）、字幕缩放（0.5–2.5）、
  描边粗细（0–4）；
- 文字颜色：白色色块 + 右侧箭头，点击循环白/暖黄/青/绿；
- 底部是字幕轨道列表（关闭 + 内嵌/外挂轨道）。

这些值写入 `PlayerUiSettings`：ExoPlayer 会实时应用字号、底部留白、
文字颜色和描边开关；LibVLC 的字幕由 libass 自己渲染。

## 手势

| 手势 | 默认行为 | 可选项 |
|---|---|---|
| 单击画面 | 显示/隐藏控制栏 | — |
| 双击左半屏 | 快退 | 快退/快进/暂停/无 |
| 双击右半屏 | 快进 | 同上 |
| 横向拖动 | 累计 seek，松手生效 | — |
| 左/右半屏纵向拖动 | 亮度 / 音量 | 可关闭 |
| 左侧长按 | 长按 2× | 倍速/慢速/快进/快退/下一集/上一集 |
| 右侧长按 | 长按 2× | 同上 |
| 长按后横滑 | 每 40dp 调整 0.25× | 可关闭 |
| 锁定后单击 | 显示/隐藏解锁按钮 | — |

双击和长按的快进/快退使用设置里的秒数；长按快进/快退会持续 seek，
松手停止。

## 时间与进度

- 进度条 6dp 高：轨道白 16%、已缓冲白 24%、已播放纯白。
- 时间格式：不足 1 小时固定两位分钟（`00:19`），超过 1 小时为 `H:MM:SS`。
- 拖动进度时左侧时间实时显示目标位置；松手才真正 seek。
- 开启「播放时间数字滚动」后，时间变化带垂直滑动过渡。

齿轮打开，分组与参考播放器一致：

- 双击屏幕左边/右边
- 左侧/右侧长按动作
- 长按倍速横滑调节
- 滑动调节亮度与音量
- 快进时间 / 快退时间

### 界面布局
- 简洁模式
- 播放时间数字滚动
- 显示长按倍速提示
- 显示信息图标
- 显示弹幕图标
- 显示屏幕锁定/旋转按钮
- 显示画中画/投屏图标
- 显示画质/版本选择按钮
- 显示下载按钮

### 播放行为
- 连续播放
- 离开自动进入画中画
- 影片方向（传感器/横屏/竖屏）
- 恢复默认设置

### 快捷入口
播放速度、清晰度、音轨、字幕、画面缩放、VR、弹幕、播放内核、
媒体信息、定时关闭、锁定屏幕。

定时关闭只作用于当前播放会话，选项为 15/30/60/90 分钟；到点自动暂停。

## 状态机

```
hidden ──tap──> visible ──3s 无操作──> hidden
visible ──拖动进度 / 长按 / 打开浮层或面板──> 暂停自动隐藏
visible ──锁定──> locked（仅保留解锁按钮；手机 3 秒后淡出）
locked ──解锁──> visible
```

暂停、播放结束、锁定时不会自动隐藏。

## 电视 / 遥控器

播放页通过 `LocalPlayerIsTv` 把电视规格提供给整个播放器子树（`PlayerTvFocus.kt`），
手机/平板不传时行为不变。

### 焦点与按键

- 方向键上显示控制栏并进入按钮焦点模式，焦点落到播放键；
- 方向键在顶栏、传输行、右下入口之间移动，OK 确认；
- 菜单键 / INFO 键打开播放器设置中心；
- 返回先退出焦点/收起控制栏，再退出播放页；
- 打开贴边浮层或分集条时，焦点自动送进第一项；关闭后回到播放键；
- 打开面板期间根节点不再消费方向键，避免和焦点系统抢事件；
- 电视端不显示左右侧边按钮，锁定入口在设置中心。

### 焦点视觉

所有可聚焦控件统一使用 `Modifier.playerTvFocus`：

- 获得焦点时 2dp 白色描边 + 12% 白色底 + 1.04 倍放大；
- 分集卡片使用 2.5dp 描边、1.05 倍放大；
- 缩放通过 `graphicsLayer` 完成，不参与布局，焦点移动不会引起重排；
- 开关（Switch）不再单独获得焦点，整行作为唯一确认目标。

### 10-foot 规格

电视模式下控件会比手机大一号：

| 控件 | 手机 | 电视 |
|---|---|---|
| 顶栏图标键 | 44dp / 24dp 图标 | 52dp / 28dp 图标 |
| 传输键 | 44dp | 54dp |
| 进度时间 | 14sp | 16sp |
| 底部入口 | 44dp | 52dp |
| 贴边浮层 | 232dp 宽、44dp 行 | 288dp 宽、52dp 行、18sp |
| 分集卡片 | 132dp 宽 | 168dp 宽 |

顶栏预留 24dp、底栏预留 24dp 作为过扫描安全区，避免电视 3%–5% 的
overscan 裁掉关闭键和传输键。遥控器操作提示只在控制栏出现后显示 6 秒，
不再长期覆盖画面。

### 手机专属能力

电视上隐藏画中画、旋转和侧边锁定入口，禁用自动进入画中画；弹幕搜索改为
手机扫码输入关键词。

## 方向与画中画

- 默认跟随传感器；右侧旋转按钮临时切换横屏/竖屏；设置中心写入持久方向。
- 右上 PiP 手动进入画中画；开启「离开自动进入画中画」后，播放中退到后台
  会自动进入 PiP 并保持播放。

## 仍未接入

- 投屏：没有 Cast SDK，点击只提示暂未接入。
- 视频下载：没有离线下载任务，点击只提示暂不支持。
- 跳过片头/片尾、章节缩略图：没有标记/雪碧图数据。
- 多线路/跨服切换：播放请求没有线路列表。
- 次字幕、Anime4K、HDR 输出：当前内核接口未暴露。
