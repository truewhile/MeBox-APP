# 播放器界面与交互

播放页的视觉与操作参考 `capyplayer` 的播放器规范：玻璃浮层 + 线性图标 + 沉浸式画面 +
底部一体化控制栏。实现位于：

| 文件 | 职责 |
|---|---|
| `feature/media/player/PlayerSkin.kt` | 设计 token、玻璃容器、图标按钮、操作项、播放/暂停图形 |
| `feature/media/player/PlayerControls.kt` | 顶部栏、进度条、传输行、操作行、侧边操作、面板、状态层 |
| `feature/media/player/PlayerScreen.kt` | 播放内核接入、手势识别、状态机、自动隐藏、锁屏、面板联动 |

## 设计 token

所有颜色、字号、圆角集中在 `PlayerSkin`，组件里不写死色值。

| 类别 | Token | 当前值 |
|---|---|---|
| 强调色 | `Accent` / `AccentStrong` | `#F2A65A` / `#FFD39B` |
| 玻璃填充 | `GlassFill` / `GlassFillStrong` | 深色 52% / 55% |
| 玻璃边框 | `GlassBorder` | 白色 14% |
| 内高光 | `Highlight` | 白色 14% |
| 主/次/弱文字 | `TextPrimary` / `TextSecondary` / `TextTertiary` | `#F4F5F7` / 62% / 38% |
| 进度轨道 | `Track` / `TrackBuffered` | 白色 16% / 32% |
| 顶/底压暗 | `ScrimTop` / `ScrimBottom` | 黑 74% / 86% |
| 标题/正文/时间 | `Headline` / `BodySmall` / `Time` | 17/24 · 600；13/18 · 500；13/16 · 600（等宽数字） |

换主题色只需要改 `PlayerSkin.Accent` 与 `AccentStrong`。

> Compose 没有跨层实时背景模糊，视频又是 SurfaceView/TextureView 绘制，因此玻璃采用
> 规范里的 Frosted/Solid 近似配方：半透明填充 + 顶部高光渐变 + 1px 边框 + 外阴影。
> 任意亮度的画面上都能读清，也不会因每帧模糊掉帧。

## 布局

从下到上：视频 → 弹幕 → 手势层 → 顶部栏 / 侧边操作 / 底部控制栏 → 手势反馈 → 状态层 → 面板。

### 顶部栏

- 150dp 压暗渐变，内容高 56dp。
- 左侧 40dp 返回按钮（12dp 圆角），标题居中（17/24 · 600），副标题 11/14 · 62%。
- 右侧最多两个图标：画中画、播放设置。

### 底部控制栏

1. 进度条：4dp 轨道，拖动时 6dp；已缓冲 32% 白；已播放为强调色渐变；
   滑块 12dp → 拖动 16dp，带 22% 强调色外圈；拖动时上方浮出玻璃时间胶囊。
2. 时间行：左侧当前时间（92% 白、600），右侧总时长（55% 白、500），等宽数字。
3. 传输行：快退 10 秒 · 56dp 玻璃播放键 · 快进 10 秒 · 下一集（无下一集时隐藏）。
4. 操作行：倍速 · 画质 · 音轨 · 字幕 · 弹幕 ·（VR 视角）· 更多 ·（矮屏时）锁定。

### 自适应

`PlayerScreen` 用 `BoxWithConstraints` 读取可用高度：

- TV 端：隐藏右侧竖排操作，所有入口收进底部操作行 + 右侧 Side Sheet。
- 高度 ≥ 600dp（平板）：显示右侧竖排操作（锁定 · 画中画 · 弹幕 · 播放设置）。
- 高度 < 600dp（手机横屏）：隐藏右侧竖排操作，把「锁定」并入底部操作行，
  避免和底部控制栏在垂直方向重叠。

## 手势

| 手势 | 行为 |
|---|---|
| 单击画面 | 显示 / 隐藏控制栏（屏幕左右边缘 16dp 不响应，留给系统返回手势） |
| 双击左/右半屏 | 快退 / 快进 10 秒，中央显示玻璃胶囊 |
| 横向拖动 | 累计 seek（整屏约 120 秒），拖动中只更新 UI，松手才真正 seek |
| 左/右半屏纵向拖动 | 亮度 / 音量，侧边显示 64×168 玻璃指示器 |
| 长按 | 临时 2.0× 倍速；保持按住并横滑，每 40dp 调整 0.25×（0.5–4.0），松手恢复原倍速 |
| 锁定后单击 | 显示 / 隐藏解锁按钮 |
| 系统返回 | 面板打开时先关面板；锁定时先解锁；否则退出播放页 |

手势在同一个 `pointerInput` 里统一判定（轻点/双击由 `detectTapGestures` 负责，
拖动与长按由自定义 `awaitEachGesture` 循环负责），避免横向 seek、纵向亮度音量、
长按倍速三个识别器互相抢事件。

## TV / 遥控器

遥控器采用两段式焦点：

| 状态 | 按键 | 行为 |
|---|---|---|
| 根节点焦点（控制栏隐藏/未进入焦点模式） | OK / 播放暂停键 | 播放 / 暂停 |
| | ◀ ▶ | 快退 / 快进 10 秒 |
| | ▲ | 显示控制栏并进入按钮焦点模式，焦点落到 56dp 播放键 |
| | ▼ | 隐藏控制栏 |
| | 菜单键 / INFO | 打开「播放设置」侧边面板 |
| | 返回 | 控制栏可见时先收起，再按退出播放页 |
| 控制栏焦点模式 | ▲ ▼ ◀ ▶ | 在传输行、操作行、顶部栏按钮之间移动 |
| | OK | 触发当前按钮 |
| | 菜单键 | 打开「播放设置」 |
| | 返回 | 退出焦点模式并收起控制栏，回到方向键快捷操作 |

- 传输行在 TV 上包含快退 10 秒、播放暂停、快进 10 秒、下一集，进入焦点模式后
  可以逐项选择，不再依赖全局左右键。
- 锁定：从「播放设置 → 锁定屏幕」进入；锁定后解锁按钮保持可见并自动获得焦点，
  OK 或返回即可解锁。
- 错误页自动聚焦「重试」，播放结束卡自动聚焦「立即播放 / 重播」，避免焦点丢失。
- TV 的侧边面板、错误页和结束页使用可聚焦 Popup（独立窗口焦点），遥控器焦点
  不会逃逸到后面的播放器控件；返回键先关闭面板。
- 所有可聚焦控件都有白色描边/底色焦点态，触控热区与焦点区域一致。

## 控制栏状态机

```
hidden ──tap──> visible ──3s 无操作──> hidden
visible ──拖动进度 / 长按倍速 / 打开面板──> 暂停自动隐藏
visible ──锁定──> locked（仅保留左侧解锁按钮；手机 3s 后淡出，TV 保持可见）
locked ──解锁──> visible
```

- 暂停、播放结束、锁定时不会自动隐藏。
- 任何点击、按钮、拖动都会重置 3 秒计时（`controlsTick`）。
- 显示/隐藏使用 200ms 淡入淡出，只移除控件层，不重建视频 Surface。
- 锁定后回到播放页的返回键会先解锁，避免误退出。

## 面板

所有面板共用 `PlayerSheetScaffold`：手机为底部贴边 Sheet（28dp 顶部圆角、36×4 拖拽手柄），
TV 为右侧 420dp Side Sheet（全高、20dp 左侧圆角、遮罩点击/返回关闭）。两者都带
标题 + 关闭按钮、内容超出时内部滚动，同一时间只允许一个面板。

| 面板 | 内容 |
|---|---|
| 播放设置 | 倍速、清晰度、音轨、字幕、画面缩放、VR、弹幕、播放内核，行尾显示当前值 |
| 倍速 | 3 列网格，`0.5×`–`3.0×`，选中项强调色底 + 边框 |
| 清晰度/音轨/字幕 | 54dp 行高，30dp 短码徽章（4K / A1 / S1 / EXO），选中行三重提示（底色 + 边框 + 勾选） |
| 弹幕 | 开关、匹配状态、手动搜索、字号/透明度/显示区域、弹幕库切换 |
| VR | 启用开关、投影/立体/显示方式、镜头校正、重新居中 |

## 状态层

- 缓冲：44dp 强调色旋转圆环 + “正在缓冲…”（11/16 · 55%）。
- 错误：错误图标、标题、两行说明、技术原因（弱化）、“重试”主按钮、“切换到 LibVLC”次按钮、返回。
- 播放结束：340dp 玻璃卡，下一集标题 + 8 秒倒计时圆环 + 取消/立即播放；
  没有下一集时显示重播/返回。
- 提示：玻璃胶囊，1.8 秒后淡出。

## 未移植的参考能力

以下能力参考项目有，但本项目当前数据或内核不提供，因此未做界面入口：

- 跳过片头/片尾：没有片头片尾标记数据。
- 选集面板：播放请求只带下一集，没有完整剧集列表。
- 缩略图预览/章节标记：没有雪碧图或章节数据。
- 投屏、旋转：播放页固定横屏全屏，投屏未接入。
- 字幕延迟/描边/颜色：当前内核接口未暴露这些参数。
